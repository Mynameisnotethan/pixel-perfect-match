# Desktop download links

1. On GitHub open **Releases → Draft a new release**, create tag `v0.1.0` (bump for later versions), click **Publish release**.
2. Wait ~10 minutes for the **Windows installer** and **Mac installer** actions to finish; both files attach to the release.
3. Share these links (they always point to the newest release):
   - Windows: `https://github.com/<you>/<repo>/releases/latest/download/Lockbox-Setup.exe`
   - Mac: `https://github.com/<you>/<repo>/releases/latest/download/Lockbox.dmg`

The installers are unsigned. Windows: click **More info → Run anyway**. Mac: drag Lockbox to Applications, then right-click it → **Open** the first time (or allow it in System Settings → Privacy & Security).
